# Настольные игры — подготовка запуска, 03.11.2026

## Готовая первая версия

В меню есть вход «Играем вместе», в нижней навигации — «Игры», в админке — «Настольные игры». Владелец создаёт встречу: точка, название игры, дата/время Москвы, 2–20 мест, условия. Гость записывается за себя и отменяет участие. Подтверждённый сервером Telegram initData определяет участника; ввод ID гостя не является авторизацией. Повторное нажатие не занимает два места. Вместимость проверяется под блокировкой. Публичный список не содержит имён и Telegram ID. Владелец видит имена записавшихся.

Раздел универсальный. Демо-встречи не публикуются. Если обработчик игр ещё не развёрнут, интерфейс показывает, что подключение не завершено, и не имитирует успешную запись. Напоминания и лист ожидания в эту версию не входят.

## Необходимое обновление серверного проекта

Добавить `apps-script/BoardGames.gs` и обновить `apps-script/Operations.gs` в существующем рабочем Google Apps Script проекте. Сохранить текущие остальные файлы и свойства. Используется уже существующее свойство `TELEGRAM_BOT_TOKEN`; не переносить секреты в GitHub. Обновить существующий deployment с тем же URL, не менять доступы или Google-таблицы. Приватные записи встреч хранятся в Script Properties, отдельные ключи для production/test.

После развёртывания: открыть раздел игр на точке 1 и 2, создать настоящую согласованную встречу в админке, записаться реальным Telegram-пользователем, проверить отмену и последний свободный слот. До этого не считать запись запущенной.

## Проверка существующего приложения

- Живые GET приложения, меню Firebase, стоп-листов и payment relay: HTTP 200.
- Публичный rescue endpoint точки 1: HTTP 200. Это подтверждает доступность обработчика, а не наличие активных акций.
- Рабочий Apps Script endpoint: HTTP 200, nonce/channel ответа присутствуют; запрос без пароля отклонён ожидаемым «Нет доступа администратора». Производственные отчёты не создавались.
- Браузер: меню, карточка капучино, добавление в корзину и сумма 300 ₽ работают.
- Оплата, банковские списания, отправка уведомлений гостям и сотрудникам не инициировались. Доставка реального отчёта/фото и реальные переходы статуса заказа требуют авторизованной проверки.
- Исправления загрузки: ограничение ожидания меню/цен/наличия, параллельная загрузка независимых настроек, сообщение с повтором вместо скрытого сбоя; неуспешный запрос не обнуляет цены. Подтверждённый пустой каталог убирает удалённые позиции.

После разрешения владельца рабочий Apps Script обновлён до версии 22 от 03.11.2026 на прежнем deployment URL. Исходный монолит сохранён; добавлен маршрут games* и обработчик BoardGames. Публичная запись и отмена требуют проверки из реального Telegram. GitHub connector вернул 403 на запись; файлы опубликованы через авторизованный веб-интерфейс GitHub. Рабочий сайт показывает вход «Игры»; браузер получил пустое расписание точки 1 без ошибки. Публичный gamesList обеих точек вернул gamesVersion=1, ok=true и events=[]. Реальная встреча ещё не создавалась; запись и отмена в Telegram требуют заключительной проверки владельцем.
